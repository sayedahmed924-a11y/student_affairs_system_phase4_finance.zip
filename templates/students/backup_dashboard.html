استعادة نسخة احتياطية

تنبيه: الاستعادة تستبدل بيانات قاعدة البيانات الحالية. لا توجد استعادة من داخل المتصفح عمدًا لتجنب تشغيل عملية مدمرة أثناء استخدام الموظفين للنظام.

  1. أوقف خدمة الويب حتى لا يكتب المستخدمون بيانات أثناء الاستعادة: docker compose stop web backup
  2. نفّذ الأمر من مجلد المشروع، مع استبدال اسم الملف باسم نسخة موجودة:
docker compose run --rm --no-deps web python manage.py restore_database student_affairs_YYYYMMDD_HHMMSS.dump --confirm RESTORE

اختر ملف قاعدة البيانات بامتداد .dump أو .sqlite3؛ يجب أن يكون ملف المستندات المطابق له باللاحقة _media.tar.gz موجودًا أيضًا. بعد نجاح الاستعادة شغّل: docker compose up -d web backup

احتفظ بنسخة إضافية خارج جهاز الخادم وعلى وسيط منفصل؛ فالنسخ داخل وحدة التخزين نفسها لا تحمي من تلف القرص أو فقدانه.
